# IntersectionObserver Demo

A small demo showing off `IntersectionObserver` for **infinite scroll**,
**lazy-loaded images**, and **reveal-on-scroll** animations. It's split into
two TypeScript services wired together with Docker Compose.

It runs fully offline. Placeholder images are SVGs generated by the
backend (`/api/items/:id/image.svg`), so no external image host is needed.

## Run it

Prerequisite: Download docker. For personal use, docker desktop is great.
Alternatively, install the docker engine separately.

```bash
docker compose up --build
```

Then open **http://localhost:5173**.

## Develop

Source folders are bind-mounted, so edits to `backend/src` and `frontend/src`
hot-reload without rebuilding the image.
